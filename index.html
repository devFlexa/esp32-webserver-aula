Ideia central

O que significa “servidor”?

O cliente é o navegador: ele pede algo. O servidor é a ESP32: ela recebe o pedido e responde. Pense em uma biblioteca: você solicita um livro pelo nome, e a biblioteca encontra e entrega o livro certo.

Parte física

Monte o circuito do LED

Você precisa de uma ESP32 DevKit (ESP32-WROOM), cabo USB de dados, LED, resistor de 220 a 1000 Ω e fios. Monte com a placa desconectada do USB.

Cuidados: use o GND da mesma placa e nunca aplique 5 V diretamente a um GPIO. Se sua ESP for C3, S3 ou outro modelo, confira o mapa de pinos e ajuste o projeto antes de gravar.

Previsão: o que deve acontecer quando o GPIO 21 passa de LOW para HIGH? Faça sua hipótese antes de testar.

Encontre cada parte do código

O projeto pronto está na pasta aula_servidor_esp32. Abra essa pasta no VS Code. Os arquivos da página ficam em data/; o programa da placa fica em src/.

aula_servidor_esp32/
├── platformio.ini       modelo da placa e SPIFFS
├── src/main.cpp         servidor, rotas e LED
└── data/
    ├── index.html       conteúdo
    ├── style.css        visual
    └── app.js           cliques e pedidos HTTP

Abra os trechos abaixo e procure as mesmas linhas nos arquivos reais. Você não precisa decorar tudo: tente descobrir a função de cada parte.

1. HTML: o que aparece na página?
<h1>Controle um LED pelo navegador</h1>
<button id="turn-on">Ligar LED</button>
<button id="turn-off">Desligar LED</button>

O id dá um nome único ao botão. O JavaScript usa esse nome para detectar o clique. Veja o HTML completo.

2. CSS: por que a página não parece texto puro?
button {
  background: #087b68;
  color: #fff;
  border-radius: 10px;
}

Essa regra pinta todos os botões e arredonda os cantos. Experimente mudar a cor em style.css.

3. JavaScript: como o clique vira um pedido?
fetch('/api/led/on', { method: 'POST' });

fetch envia o pedido para a ESP32. O arquivo app.js também lê a resposta e atualiza o indicador na tela.

4. Arduino: como a ESP32 recebe e age?
server.on("/api/led/on", HTTP_POST, []() { setLed(true); });
digitalWrite(LED_PIN, HIGH);

A primeira linha associa uma rota a uma ação. A segunda representa a mudança elétrica no pino. Leia main.cpp.

Por que há dois envios? Upload grava o programa da ESP32. Upload Filesystem Image grava os arquivos HTML, CSS e JavaScript da pasta data/.
Hora de fazer

Da placa à página, passo a passo

A ESP32 é um microcontrolador: um pequeno computador que executa um programa e conversa com componentes eletrônicos. Nesta atividade, vamos enviar duas partes para ela: o programa que controla o LED e os arquivos da página que aparecem no navegador.

🧰VS Code + PlatformIOVS Code significa Visual Studio Code: é o editor de código. PlatformIO é a extensão que organiza o projeto, compila o programa e o envia à placa.
🧠Programa da placaO arquivo src/main.cpp vira o firmware: o programa que roda na ESP32. O botão Upload grava esse firmware.
📁Arquivos da páginaHTML, CSS e JavaScript estão em data/. Eles vão para uma área da memória flash chamada SPIFFS (sistema de arquivos na memória da placa).
Guarde esta diferença: mudou main.cpp? Faça Upload. Mudou um arquivo da pasta data/? Faça Upload Filesystem Image. Para mudanças nas duas partes, repita os dois envios.
  1. Abra a pasta do projeto. No VS Code, use File → Open Folder (Arquivo → Abrir Pasta) e escolha aula_servidor_esp32. O arquivo platformio.ini informa ao PlatformIO qual é a placa (esp32dev), qual é o framework (arduino) e como preparar os arquivos. Confira: você consegue ver as pastas src e data no explorador?
  2. Conecte e grave o programa. Use um cabo USB de dados para conectar a ESP32. Em PlatformIO → Project Tasks → esp32dev, execute Upload (enviar). O PlatformIO compila o C++ em instruções para a placa e grava o firmware na memória flash. Confira: a tarefa termina com uma mensagem de sucesso, sem erro em vermelho?
  3. Envie os arquivos da página. No mesmo menu de tarefas, execute Upload Filesystem Image. Filesystem significa “sistema de arquivos”: o PlatformIO empacota index.html, style.css e app.js da pasta data/ e os grava no SPIFFS (SPI Flash File System). A flash guarda esses arquivos mesmo depois de desligar a placa. Confira: essa segunda tarefa também termina com sucesso?
  4. Leia o que a placa informa. Abra o Serial Monitor, uma janela que mostra mensagens enviadas pela ESP32 pelo cabo USB. Ajuste para 115200 baud: baud é a velocidade de comunicação; o monitor e o programa precisam usar o mesmo valor para o texto aparecer corretamente. Procure Abra: http://192.168.4.1. Confira: aparece também o nome da rede ESP32-Aula?
  5. Conecte-se à rede da ESP32. No Wi-Fi do celular ou computador, escolha ESP32-Aula e digite AulaESP32. A placa está funcionando como ponto de acesso: ela cria sua própria rede, sem precisar de roteador. Confira: o aparelho permanece conectado mesmo que apareça o aviso “sem Internet”?
  6. Abra e teste a página. No navegador, digite http://192.168.4.1. Esse número é o endereço IP (Internet Protocol) da ESP32 dentro da rede que ela criou; HTTP (Hypertext Transfer Protocol) é a forma como navegador e servidor trocam pedidos e respostas. Aperte Ligar LED e Desligar LED. Confira: o LED real e o indicador da página mudam juntos?

Mini dicionário para consultar durante a prática

NomeO que significa aqui
USBUniversal Serial Bus: cabo usado para alimentar a placa e transferir o programa e as mensagens.
GPIOGeneral Purpose Input/Output: pino que o programa pode usar como entrada ou saída. O GPIO 21 liga e desliga o LED.
LEDLight Emitting Diode: componente que emite luz. Ele tem polaridade, por isso a posição das pernas importa.
HTML / CSSHyperText Markup Language organiza o conteúdo da página; Cascading Style Sheets define a aparência.
Framework ArduinoConjunto de funções prontas, como digitalWrite, que facilita programar a ESP32 em C++.

Quer usar comandos? No terminal aberto dentro da pasta aula_servidor_esp32, estes são os equivalentes aos três botões do PlatformIO: enviar programa, enviar página e abrir o monitor.

pio run -t upload
pio run -t uploadfs
pio device monitor -b 115200

pio é o comando do PlatformIO; uploadfs significa “enviar o sistema de arquivos”. Se o comando pio não for reconhecido, use os botões da extensão no VS Code.
